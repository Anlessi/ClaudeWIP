# Repository-wide decisions

Decisions about how we work in this repository (workflow, tooling, conventions). Project decisions live in
each project's own `docs/decisions/` folder. The format is in `.claude/skills/wrap-up/decision-template.md`.

| # | Decision | Status |
|---|---|---|
| [0001](0001-branch-and-squash-merge-workflow.md) | Every change goes through a branch and a squash-merged pull request, using the GitHub CLI | Accepted |
| [0002](0002-pr-descriptions-from-a-file.md) | Pass pull request descriptions to `gh` from a file | Accepted |
| [0003](0003-no-stacked-pull-requests.md) | No stacked pull requests | Accepted |
| [0004](0004-decision-records-and-wrap-up.md) | Keep decisions and context in the repository, updated by `/wrap-up` before every pull request | Accepted |
